# CoinPliot-
CRYPTOCURRENCY LIVE TRACKER # 🚀 CoinPilot — Live Crypto Tracker
CoinPilot is an educational web development project created to explore cryptocurrency market data, API integration, and interactive dashboard development.
The project uses the **CoinGecko API** to display cryptocurrency prices, market statistics, and price-performance data in a simple and user-friendly interface.

## 🎯 Purpose
This project was developed for **educational purposes** to gain practical experience in:
- Working with APIs
- Fetching and processing live data
- Building interactive web dashboards
- Using JavaScript for dynamic content
- Understanding basic cryptocurrency market metrics

## ✨ Features
- 🔎 Search cryptocurrencies
- 📊 View cryptocurrency prices and market data
- 📈 Track 1H, 24H, and 7D price changes
- 💰 View market capitalization and trading volume
- 🏆 View cryptocurrency rankings
- 📉 View 7-day price trends
- 🔍 Explore individual cryptocurrency details
- ⚖️ Compare cryptocurrencies
- 🔄 Refresh and update market data
- 🛡️ Fallback data when live data is unavailable

## 🛠️ Technologies Used
- **HTML5** — Website structure
- **CSS3** — Styling and dashboard design
- **JavaScript** — Functionality and dynamic data
- **CoinGecko API** — Cryptocurrency market data

## 📚 What I Learned
Through this project, I gained practical experience with:
- REST API integration
- JavaScript `fetch()` and asynchronous functions
- JSON data handling
- Dynamic DOM manipulation
- Search and sorting functionality
- Data visualization
- Interactive dashboard design
- Handling API errors and fallback data
